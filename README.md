## Featured Projects / Основные проекты

### [Mini-CRM](https://github.com/Zemajj/Mini-CRM)

A learning CRM built with PHP 8.5 and without a framework. I am creating the MVC structure, router, and PostgreSQL access myself to understand what frameworks usually provide.

*Учебная CRM на PHP 8.5 без фреймворка. Я самостоятельно создаю MVC-структуру, роутер и работу с PostgreSQL, чтобы понять, что обычно предоставляет фреймворк.*

`PHP 8.5` · `PostgreSQL` · `PDO` · `Composer` · `PSR-4`

### [task-api](https://github.com/Zemajj/task-api)

A REST API for task management built with Laravel 13. It provides CRUD operations and API routes for tasks.

*REST API для управления задачами на Laravel 13. Проект предоставляет CRUD-операции и API-маршруты для задач.*

`PHP 8.3` · `Laravel 13` · `SQLite` · `Bruno`
